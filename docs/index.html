Windows screensaver · MIT

Live time, date, and weather — as Terminal Text Effects.

An Omarchy-style TTE screensaver for Windows 11. The clock is the ASCII. Effects chew through every character, so the house screen never burns in and never looks static.

Download the .scr Source on GitHub

What it does

  • Figlet clock + date, optional weather from Open-Meteo (no API key).
  • 35+ TTE effects — Decrypt, Matrix, Rain, Beams, and friends — cycling at random.
  • Refreshes when an effect starts (or after 45s), so the minute never freezes.
  • Real Windows screensaver. Right-click the .scr → Install, then Settings for lat/lon, °C/°F, 12/24h.

Install

  • Grab tte-screensaver.scr from Releases (or build with build.bat).
  • Right-click → Install, or copy to C:\Windows\System32.
  • Personalize → Lock screen → Screen saver settings → tte-screensaver.
  • Settings: paste lat/lon from Google Maps for weather. Leave empty for time/date only.
